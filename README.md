
# Transportation Problems Learning Platform

An educational website for studying and solving Transportation Problems in Quantitative Methods and Operations Research.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Features

### Educational Modules

- Introduction to Transportation Problems
- Transportation Terminologies
- Mathematical Formulation
- Transportation Tables
- Balanced Transportation Problems
- Unbalanced Transportation Problems

### Initial Allocation Methods

- North-West Corner Method
- Least Cost Method
- Vogel's Approximation Method
- Russell's Approximation Method

### Optimization Methods

- Stepping Stone Method
- MODI Method
- Transportation Simplex Method

### Special Cases

- Degeneracy
- Multiple Optimal Solutions
- Maximization
- Prohibited Routes
- Dummy Sources and Destinations

### Tools

- Interactive Transportation Solver
- Worked Examples
- Practice Exercises
- Formula Reference
- Glossary

## Installation

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open index.html using a browser.
4. Alternatively, use the VS Code Live Server extension.

No Node.js installation or build process is required.

## Project Structure

- index.html: Landing page
- pages/: Educational pages
- pages/methods/: Transportation method lessons
- pages/special-cases/: Special topic lessons
- assets/css/: Website styles
- assets/js/: Mathematical algorithms and functionality

## Important Notes

This project is an educational implementation.

The current interactive solver includes initial allocation algorithms and a basic MODI optimization implementation. Degenerate basis handling, robust closed-loop construction, prohibited-route input, maximization calculations, and fully automated Stepping Stone optimization require further development and validation.

Always verify mathematical outputs before using them in graded academic work.
