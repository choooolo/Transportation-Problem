Optimization Methods
METHOD 06 · OPTIMIZATION

MODI Method (Modified Distribution Method)

The MODI method, also called the U-V Method, is used to test and improve a basic feasible transportation solution.

Step 1: Find the Basic Cells

Identify the occupied cells in your transportation table. A non-degenerate basis should have:

m + n − 1

Step 2: Calculate U and V Values

uᵢ + vⱼ = cᵢⱼ

Use this equation for each basic cell. Set one potential, commonly u₁, equal to zero.

Step 3: Calculate Opportunity Costs

Δᵢⱼ = cᵢⱼ − uᵢ − vⱼ

Step 4: Test Optimality

For a minimization problem, the solution is optimal if every eligible non-basic cell has Δᵢⱼ ≥ 0.

Step 5: Improve the Solution

  1. Select the most negative reduced cost.
  2. Make that unoccupied cell the entering cell.
  3. Construct a valid closed loop.
  4. Assign alternating plus and minus signs.
  5. Find the smallest allocation in the minus positions.
  6. Add and subtract this quantity along the loop.
  7. Recalculate the U and V values.
  8. Repeat the optimality test.

Important Reminder

If there are fewer than m+n−1 independent basic cells, address degeneracy before calculating MODI potentials.
