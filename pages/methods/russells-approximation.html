METHOD 04 · INITIAL ALLOCATION

Russell's Approximation Method (RAM)

Russell's Approximation Method is an alternative initial solution method that uses row and column maximum costs to estimate allocation priority.

Formula

Δᵢⱼ = cᵢⱼ − uᵢ − vⱼ

Where:

  • cᵢⱼ = Unit transportation cost.
  • uᵢ = Maximum available cost in row i.
  • vⱼ = Maximum available cost in column j.

Procedure

  1. Find the maximum cost in each active row.
  2. Find the maximum cost in each active column.
  3. Calculate the evaluation value for each eligible cell.
  4. Select the smallest, usually most negative, evaluation value.
  5. Allocate the maximum possible quantity.
  6. Update supply and demand.
  7. Recalculate row and column maximum values.
  8. Repeat until all allocations are complete.

Important Note

RAM is an additional approximation method. It is not always taught alongside NWCM, LCM, and VAM in introductory courses.
