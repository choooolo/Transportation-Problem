METHOD 07 · ADVANCED OPTIMIZATION

Transportation Simplex Method

The Transportation Simplex Method is a specialized form of the simplex algorithm designed for transportation problems.

Important Concepts

Basic Variables

Variables currently included in the transportation basis.

Non-Basic Variables

Variables currently outside the basis.

Entering Variable

A variable selected to enter the basis.

Leaving Variable

A basic variable removed during a pivot.

Pivot

An adjustment that changes the current basis.

Reduced Cost

Indicates whether an entering variable can improve the objective.

General Procedure

  1. Obtain an initial basic feasible solution.
  2. Establish a valid basis of m+n−1 independent cells.
  3. Calculate reduced costs.
  4. Select an entering variable if improvement is possible.
  5. Construct a closed loop.
  6. Perform the pivot adjustment.
  7. Update the basis.
  8. Repeat until optimality is achieved.

Relationship with MODI

MODI provides a convenient way to calculate the potentials and reduced costs used in the transportation simplex procedure.
