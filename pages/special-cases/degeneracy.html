Special Cases

Degeneracy in Transportation Problems

Degeneracy occurs when the number of independent basic cells is less than the required number of basic variables.

Required Basic Cells = m + n − 1

Example

For a transportation table with 3 sources and 3 destinations:

3 + 3 − 1 = 5

The solution should have five independent basic cells.

How to Resolve Degeneracy

  1. Count the independent basic cells.
  2. Compare the count with m+n−1.
  3. If there are fewer, select an appropriate independent empty cell.
  4. Introduce a very small quantity ε.
  5. Ensure that the selected cell does not create a closed-loop dependency.
  6. Continue the optimization process using the completed basis.
Epsilon is a bookkeeping value, not an ordinary positive shipment. A zero allocation should not automatically be counted as a basic cell unless it is explicitly retained as part of an independent basis.
