Special Cases

Maximization Transportation Problems

In a maximization transportation problem, the objective is to obtain the highest possible total profit instead of minimizing transportation cost.

Conversion Formula

c'ᵢⱼ = M − pᵢⱼ

Where:

  • M = Largest profit in the matrix.
  • pᵢⱼ = Original unit profit.
  • c'ᵢⱼ = Converted minimization cost.

Example

RouteOriginal ProfitConverted Cost (M = 20)
A200
B155
C1010

Procedure

  1. Find the largest profit value.
  2. Subtract each profit from the maximum profit.
  3. Use the resulting matrix as the equivalent minimization model.
  4. Solve the transportation allocation problem.
  5. Calculate the original total profit using the original profit matrix.
This conversion assumes a fixed total quantity shipped. If the model has different constraints or route restrictions, verify the equivalence before using it.
